MoviesAdmin

This project is a C# web application I am building for my INET2005 Web Application Programming course.

Over four sprints, I will be developing the site into a movie review website like Rotten Tomatoes.
Each sprint will add new features and build on the work from the previous sprint until i have a functional movie review platform.


Description

MoviesAdmin is a semester-long project focused on building a movie review website.
The goal is to create a site where users can browse movies, leave reviews, and give ratings.

Throughout the four sprints, I will be working with web development concepts, including:
- MVC architecture
- Routing, controllers, and views
- Models and validation
- Entity Framework and scaffolding
- File handling
- Database relationships
- User authentication
- Web application security
- APIs and SQL
- Cloud hosting and deployment
- UI tools such as TypeScript, Tailwind CSS, and React
